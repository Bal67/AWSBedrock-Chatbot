# Attribution and Use of AI Tools

This project, **AWSBedrock-Chatbot**, integrates a conversational AI interface with Amazon Bedrock to power intelligent responses using Claude. The project benefited from AI-assisted development tools to streamline implementation, testing, and documentation.

## Tools and Services Used

- **ChatGPT by OpenAI (GPT-4o)**:
  - Assisted with code structuring and modularization
  - Helped debug session issues and prompt formatting
- **Amazon Bedrock**:
  - Used to access **Anthropic Claude** for chatbot functionality
- **Streamlit**:
  - Used for creating the chatbot interface
- **boto3**:
  - Used for AWS SDK integration and Bedrock runtime client

## AI Contributions

- Advised on error handling and model invocation
- Drafted the initial architecture and authentication logic
- Contributed to UX flow (login prompts, chat input/output rendering)


## Authorship Statement

While AI tools were used to accelerate development and writing, the project author maintained full control over the implementation, security configurations, and ethical safeguards. All AI-generated content was reviewed and adapted as needed.
